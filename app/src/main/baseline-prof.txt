# Written by hand, next to the profile :baselineprofile generates (src/release/generated/). That one
# records what its journeys ran into on one phone, in one channel read as a guest, on one day: the
# code that runs most — every message on its way in, all night in the background, and the chat
# being drawn — is only as complete there as the messages that happened to arrive, and what only a
# login runs is not there at all. Without a rule that code starts out interpreted after every
# install and update, until Android's background compilation gets round to it, which can take a day.
#
# Whole packages rather than single methods, so that the rules do not go stale when a method is
# renamed. The build merges both files; R8 carries the rules over to the names it gives.
#
#   H  hot: compiled ahead of time     S  used at startup     P  used after startup
#   L  a class to load and initialize early
